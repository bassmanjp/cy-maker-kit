GeekerMaker

Kevin's GeekerMaker upgrade

Hey Kevin. This gives your Claude some of the habits that make mine productive. It plans before it builds, checks its work on the real thing, and remembers what it learns. That goes for any project: code, electronics, a website, a 3D print, a plan for something you're building.

You do three small things. Claude does the rest.

Step 1 of 3

Make a "Projects" folder

In Finder, press ⌘ ⇧ H to open your home folder. Make a new folder called Projects.

All your projects will live there.

Step 2 of 3

Open the Code tab

In the Claude app, click Code at the top (not Chat, not Cowork). Start a new session and pick your Projects folder.

Next to the message box, set the mode to Auto. Claude then gets on with the work and only stops for anything risky. If you don't see Auto, pick Accept edits.

Code works right on your Mac, with your files, your tools and anything you plug in.

Step 3 of 3

Paste this to Claude

Set me up with the Cy Maker Kit: clone https://github.com/bassmanjp/cy-maker-kit into this folder (if git isn't installed, set up Apple's developer tools first), then open cy-maker-kit/START-HERE.md and walk me through it one step at a time.

Now Claude takes over

It walks you through setup one step at a time, about 45 minutes. It only stops when it needs your hands:

  • Clicking Install on Apple's developer tools pop-up.
  • Making a free GitHub account, your projects' safe copy.
  • Telling it what you want to build first.

No API keys, no extra cost, no terminal.

Every project after that

Open the Code tab on the project's folder, then:

/architect → work on your project → /wrap

/architect tells you where things stand. /wrap saves everything to GitHub. If you're ever lost, type /guide.

Have fun. Build something weird.

Stuck? Ask Claude /guide, or text JP.
