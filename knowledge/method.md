# Method, in one page

The full version is `cy/ETHOS.md` (how Claude works and decides) and
`cy/MODELS.md` (which model and helper does what). For any project:

1. Name the check first; done means it passed on the real thing (the board,
   the app, the printed part or the finished writing).
2. Small steps, each committed and pushed.
3. Keep logic testable and run the project's tests; use practical checks
   for designs and writing. Hardware time is for hardware problems.
4. Fresh-eyes check before calling a feature done; two rounds, then ship.
   Safety problems, failing tests and other blocking findings still need fixing.
5. Write down surprises: PITFALLS.md, DECISIONS.md, NOTES.md.
6. One recommendation; Claude decides technical details, you decide money,
   safety and purpose.
7. Three failed tries: stop and debug from known facts, outside in.
8. Safety rules are not negotiable; everything else is fixable.
